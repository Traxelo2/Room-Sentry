# Screenshots Guide

The repo includes placeholder preview SVGs in `docs/assets/` so the README looks presentable before real screenshots are captured.

## Recommended real screenshots

Capture these after running RoomSentry locally:

1. **Dashboard status** — armed/disarmed state, heartbeat, latest preview.
2. **Event timeline** — several sample events with timestamps.
3. **Snapshot gallery** — saved snapshots, ideally with faces blurred or synthetic test footage.
4. **Settings GUI** — safe example config only; never show real tokens or private camera URLs.
5. **Diagnostics output** — camera/model/config checks.

## Privacy rules for screenshots

- Do not show people without permission.
- Blur faces, private rooms, addresses, tokens, and camera URLs.
- Prefer a staged/synthetic test scene.
- Do not upload snapshots from shared/private areas.

## File names

Suggested final screenshot paths:

```text
docs/assets/dashboard.png
docs/assets/timeline.png
docs/assets/settings.png
docs/assets/diagnostics.png
```
