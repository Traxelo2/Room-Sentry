# Roadmap

RoomSentry is currently an alpha local-first room watcher. The goal is to keep it useful, lightweight, private by default, and easy to run on normal home PCs.

## v1.5 - Stability and polish

- Better settings validation with friendly error messages
- More reliable camera reconnect logic
- Better dashboard layout on mobile
- Dashboard search/filter for events
- Snapshot/clip retention controls in the UI
- Safer first-run setup flow
- Optional system tray app on Windows
- Better Linux desktop launchers

## v1.6 - Zones and rules

- Visual zone editor in the dashboard
- Ignore zones and alert zones from the browser
- Time schedules for armed/disarmed mode
- Per-zone alert rules
- Per-integration alert rules

## v1.7 - Packaging

- One-click Windows installer
- Portable Windows release zip
- Linux AppImage or simple package script
- Optional Docker image for dashboard-only/event browsing

## v2.0 - Multi-camera and integrations

- Multiple camera profiles
- Old phone/IP camera support guide
- Home Assistant integration
- Plugin folder for custom actions
- Better webhook payload schema
- Private remote access guide using Tailscale/WireGuard

## Later ideas

- Local AI event descriptions
- Object moved/door-open detection
- Daily summary reports
- Ask-your-event-history interface
- Optional face blurring improvements
- Exportable privacy/audit reports

## v1.6 ideas

- Zone drawing UI in the dashboard.
- One-click test event generator.
- Mobile-friendly dashboard layout pass.
- Installable Windows tray app wrapper.
- First-run setup wizard.
- Optional password/token screen for dashboard commands.
