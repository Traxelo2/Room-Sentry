# Recommended GitHub Labels

GitHub does not automatically create labels from this file. Use it as a setup checklist.

```text
bug — Something is broken
enhancement — New feature or improvement
good first issue — Good for new contributors
help wanted — External help wanted
needs-triage — Needs maintainer review
privacy — Privacy defaults, data handling, docs
safety — Misuse prevention and permission-based monitoring
docs — Documentation
windows — Windows-specific work
linux — Linux-specific work
dashboard — Dashboard/API work
detector — YOLO/OpenCV/motion detection
alerts — Discord/Telegram/ntfy/webhook/TTS
ci — GitHub Actions and automation
dependencies — Dependency updates
release — Release packaging
```
